# 修正内容の確認 (Walkthrough) - 政策機能の改善と権限修正

## 変更内容

### UI改善
- `frontend/src/app/dashboard/sessions/[id]/page.tsx` から、重複していた末尾の新規作成フォームを削除しました。
- これにより、上部の「新規立案」ボタンをクリックした際、ボタンのすぐ下にフォームが1つだけ表示されるようになります。

### 権限修正
- `backend/api/dashboard.py` の `create_policy`, `update_policy`, `delete_policy` エンドポイントを修正しました。
- 以前は管理者ロールのみに制限されていましたが、現在は**同じ組織に所属していれば一般メンバーも可能**です。
- フロントエンド側でもボタンの表示制限がなかったため、これで一般メンバーがエラーなく政策を保存・編集・削除できるようになります。

## 確認事項
- 一般メンバーのアカウントでログインし、政策の「新規立案」「編集」「削除」がエラーなく（403エラーが出ずに）実行できること。
- 「新規立案」時にフォームが二重に表示されないこと。
